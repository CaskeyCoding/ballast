# Corpus

This is the knowledge base for the RAG pipeline: curated U.S. personal-finance and investing
education, paraphrased from authoritative public-domain federal sources (the SEC's investor.gov, the
IRS, the CFPB, the FDIC, the U.S. Treasury / TreasuryDirect, and the Bureau of Labor Statistics),
plus a small set of the author's own investing-methodology notes. All of it is general, impersonal
education, not personalized advice.

The federal documents are U.S. government works and are therefore in the public domain under
17 U.S.C. 105; citation of the source agency is requested as a courtesy. The methodology notes are
the author's own public educational summaries. Provenance is carried in each document's frontmatter
(`title / source / url / published / license / attribution_string`) so retrieved chunks can be
cited back to where they came from.

No private or personal data of any kind belongs here. This README itself is excluded from ingestion
(it describes the corpus, it is not knowledge-base content).
